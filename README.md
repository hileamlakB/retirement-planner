# Financial Planner

A comprehensive retirement investment calculator that helps you compare different retirement investment strategies by projecting the growth of various account types over time.

## Features

- Compare pre-tax vs. after-tax retirement accounts
- Visualize employer match benefits
- Understand tax-efficient withdrawal strategies
- Calculate liquidation values at any age
- Export data to Excel
- Download chart as image

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Recharts for data visualization
- XLSX for Excel export
- HTML2Canvas for chart image export

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
